# Start Here — macOS

1. Unzip `trustify-banking-grc-assessment.zip`.
2. Open VS Code → File → Open Folder → `trustify-banking-grc-assessment`.
3. Read `README.md`, `DISCLAIMER.md`, and `01-project-charter/project-brief.md`.
4. Start with `02-threat-intelligence/evidence-register.csv`. Find the exact original public source for EV-001 and fill source URL, publication date, precise claim, and verification notes.
5. Update `sources/EV-001.md` with an independent summary and limitations; do not copy full copyrighted articles.
6. Check `03-risk-assessment/cyber-risk-register.csv`; all risk scenarios are hypothetical.
7. Record changes in `09-quality-assurance/review-log.md`.
