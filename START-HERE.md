This file is a reading guide, not a request to initialize Git again. The repository is already connected to GitHub.

## If you are reviewing the project

1. Read `DISCLAIMER.md`.
2. Read `PROJECT-OVERVIEW.md` for the project purpose, scope and method.
3. Read `PROJECT-TIMELINE.md` for the activity history.
4. Review `ISSUE-REGISTER.csv` and `FINDINGS-AND-REMEDIATION.csv` for open and closed items.
5. Read `PROJECT-RESULTS.md` and `07-executive-report/executive-summary.md`.
6. Inspect source evidence and test artifacts in folders `02` and `04`.

## If you are continuing the assessment

- Do not change a PENDING or NOT_ASSESSED status without new supporting evidence.
- Keep baseline FAIL and retest PASS as separate historical records.
- Use synthetic data only; never insert real customer or bank information.
- Record material changes in `09-quality-assurance/review-log.md` and `CHANGELOG.md`.
- Verify regulatory clauses against the official full text and document the entity/activity applicability.
